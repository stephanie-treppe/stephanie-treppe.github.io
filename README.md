# Stephanie Treppe – Webpräsenz

Offizielle Webpräsenz von **Stephanie Treppe** (Inklusionscoach & staatlich geprüfte Betriebswirtin).

🌐 **Live-Webseite:** [https://stephanie-treppe.github.io](https://stephanie-treppe.github.io)

---

## 📂 Struktur

* **`index.html`**: Startseite mit Zielgruppenweiche (*Für Dich* vs. *Für Unternehmen*), Hero-Bereich und Über-mich-Vorstellung.
* **`fuer-dich.html`**: Seite für Privatpersonen, Erwachsene mit ADHS/Autismus, FLINTA & IT-Fachkräfte mit interaktivem **Quinnometer** (Stufen 1–5), Coaching-Modulen (*Selbstorganisation*, *Prokrastination*) und transparenten Preisen.
* **`fuer-unternehmen.html`**: Seite für Unternehmen, HR & Führungskräfte mit den vier B2B-Leistungsbausteinen (Mitarbeitercoaching, Teamcoaching, Führungskräfte-Coaching, Workshops).
* **`assets/img/`**: Web-optimierte Assets (Maskottchen Quinn in verschiedenen Stufen & Porträts von Stephanie).
* **`.github/workflows/deploy.yml`**: GitHub Actions Workflow für das automatische Deployment auf GitHub Pages.

---

## 🚀 Deployment

Jeder Push auf den `main`-Branch löst automatisch die GitHub Action aus und aktualisiert die Webseite unter `https://stephanie-treppe.github.io`.
